# xiaodi电竞

> 微信小程序支付一站式解决方案：普通直连商户 v2 支付 + 小程序虚拟支付（道具/代币），基于云开发云函数，零服务器维护。

## 项目简介

本项目为微信小程序提供**完整的前后端支付能力**，涵盖两种支付模式：

- **普通微信支付 v2**：自封装统一下单、回调验签、退款等 API，不使用云开发内置支付接口，完全自主可控。
- **小程序虚拟支付（待开发）**：支持道具直购（`short_series_goods`）和代币充值（`short_series_coin`），包含服务端双签名（paySig + signature）及订单回调发货。

所有逻辑均运行于**云开发云函数**中，无需购买服务器，天然支持弹性伸缩。前端通过 `wx.cloud.callFunction` 调用，后端自动处理签名、订单状态、幂等发货。

### 特性

- ✅ 普通直连商户 v2 支付（XML + MD5 签名）
- ✅ 虚拟支付道具直购 & 代币充值
- ✅ 云函数双签名（paySig / signature）自动计算
- ✅ 回调通知处理（notify_url + 云开发消息推送）
- ✅ 订单状态机（pending → confirmed → completed）
- ✅ 手机号获取（云调用版，无需维护 access_token）

## 快速开始

### 前置条件

1. 已完成微信小程序注册并认证（企业）
2. 已开通**微信支付**（普通直连商户）
3. 已开通**小程序虚拟支付**（MP 后台 → 虚拟支付，获取 AppKey）
4. 已创建云开发环境

### 安装

将本仓库克隆到本地，然后在云开发环境中部署云函数

### 访问控制部署注意事项

- 云函数独立部署；更新小程序的同时重新部署本次修改的全部云函数，包括已停用直接记账的 `addUserConsumption`。用户和陪玩登录及授权绑定注册时的微信 OpenID，已有账号须保留正确的 `openid`。
- 在云数据库中创建 `auditLogs` 集合，仅允许云函数写入，禁止客户端读写；订单状态、商品上下架、陪玩服务范围和用户封禁等成功操作会写入审计记录。应限制后台审计数据访问并设置适当的保留策略。
- 云函数权限检查不能代替云数据库安全规则。部署前必须禁止客户端修改 `users.isAdmin`、`openid`、`isAvailable`、`consumption`，`partners.openid`、`isAvailable`，`goods` 的管理字段及订单的所有权、支付和状态字段；也应限制敏感数据读取。目前项目仍有直接从小程序创建、评价和删除订单的代码，需要在数据库规则中按字段和所有者限制这些操作，或迁移到受保护的云函数。规则未配置时，不应将本项目视为安全部署。
- 当前支付金额根据预下单时的商品价格计算，确认订单时的消费统计使用当时的商品价格；价格变更可能导致统计与实付金额不同。支付订单绑定、退款、幂等对账及不可变价格快照仍需服务端实现。
